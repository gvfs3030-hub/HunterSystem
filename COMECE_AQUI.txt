HUNTER SYSTEM — COMO GERAR O EXECUTÁVEL PELO NAVEGADOR

1. Baixe e extraia HunterSystem_Windows_Source.zip no computador.
2. No GitHub, crie um repositório vazio chamado hunter-system (sem README automático, se possível).
3. Abra Add file > Upload files e envie main.py, game_data.py, README.md, requirements.txt e .gitignore.
4. Para criar o workflow, use Add file > Create new file. No nome do arquivo, digite exatamente:
   .github/workflows/build-windows.yml
   Cole o conteúdo do arquivo .github/workflows/build-windows.yml que veio no ZIP e faça commit.
   (Se o site aceitar enviar pastas, pode enviar a pasta .github inteira junto com os demais arquivos.)
5. Abra Actions > Build Hunter System para Windows > Run workflow.
6. Espere a execução ficar verde. Entre nela, encontre Artifacts e baixe HunterSystem-Windows.
7. Extraia esse artefato e execute HunterSystem.exe no Windows.

O ZIP de origem NÃO contém o .exe: o GitHub Actions compila o executável para Windows.
O progresso do aplicativo fica no seu próprio computador e pode ser exportado pela tela Configuração.
